# GraphX

An interactive math equation plotter built with C++ and OpenGL.

## Features

- 3D explicit function plotting
- 2D fractal rendering with shaders

## Requirements

- C++17 or later
- OpenGL 3.3 or later
- GLFW
- GLAD
- GLM

## Build

Build instructions will be added once the project build configuration is available.

## Usage

GraphX is intended to visualize mathematical functions and fractals in real time.

Example functions:

```text
z = sin(sqrt(x^2 + y^2))
z = x^2 - y^2
```
